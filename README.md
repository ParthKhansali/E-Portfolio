# Parth Khansali — Developer Portfolio

Personal developer portfolio built with **Next.js 16** (App Router, Turbopack), **React 19**, **Tailwind CSS v4**, **Framer Motion**, **Lenis Smooth Scroll**, **Firebase Auth (Google Sign-In)**, and **Cloud Firestore**.

---

## 🚀 Key Highlights

- **60+ FPS Custom Cursor**: Zero-lag GPU hardware-accelerated cursor (`translate3d`) with reactive link hover states.
- **Interactive Nether Portal**: Dual-band crisscrossing skills marquee with floating voxel vortex aesthetics.
- **Developer Systems Deck**: Live GitHub metrics, WakaTime telemetry, and an interactive retro Spotify music player.
- **Enchanted Book Project Showcase**: Featured engineering projects with custom Standard Galactic Alphabet (SGA) runes and breathing depth cards.
- **Authentic Community Guestbook**: Bot-free verified notes powered by Firebase Auth Google Sign-In and live Cloud Firestore collections.
- **Live Visitor Telemetry**: Session-deduplicated page views counter and visitor geolocation badge.
- **A4 PDF Resume Modal**: Synchronized embedded PDF viewer with one-click download and coordinated header transitions.
- **Command Palette (`Cmd+K`)**: Keyboard-accessible quick navigation launcher.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Static Export)
- **Language**: TypeScript
- **Runtime**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) + CSS Custom Properties
- **Animation**: [Framer Motion 12](https://motion.dev/), [Lenis](https://lenis.darkroom.engineering/)
- **Backend & Auth**: [Firebase](https://firebase.google.com/) (Google Auth & Cloud Firestore)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started

### 1. Clone & Install
```bash
git clone https://github.com/ParthKhansali/E-Portfolio.git
cd E-Portfolio
npm install
```

### 2. Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Generate Resume PDF
```bash
npm run generate:resume
```

### 4. Production Build
```bash
npm run build
```
